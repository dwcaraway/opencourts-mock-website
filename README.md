# OpenCourts Website

This repository controls the **opencourts.fyi** website — the public-facing web presence for the OpenCourts project.

## Deployment

Changes merged to the `main` branch are **automatically published** to the website via GitHub Pages. The site is hosted at [opencourts.fyi](https://opencourts.fyi).

### Domain Configuration

The site is configured to use the custom domain `opencourts.fyi` via the `docs/CNAME` file. GitHub Pages automatically serves the site from the `docs/` directory.

## Contributing

For contribution guidelines, see [governance-charter.md](governance-charter.md).

## Publishing Process

1. Make changes to files in the `docs/` directory
2. Commit and push to the `main` branch
3. GitHub Pages automatically builds and publishes the changes to opencourts.fyi

No manual deployment steps are required.
